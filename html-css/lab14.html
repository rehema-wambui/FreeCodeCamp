Getting Started

HTML (HyperText Markup Language) gives web content its structure and meaning.

Elements are written with tags, and most elements have an opening and a closing tag.

A basic paragraph can be written as <p>Hello, web!</p>.

Document Structure

A complete HTML document begins with a declaration that identifies the HTML version.

The <head> contains page metadata, while the <body> contains visible content.

  • Use <html> as the document root.
  • Set the document language with the lang attribute.
Text and Headings

Headings communicate the hierarchy of a page, from the main title to smaller subtopics.

Choose heading levels according to meaning rather than visual size.

Use <strong> for important text and <em> for emphasis.

  • <h1> introduces the page's primary topic.
  • <p> groups a paragraph of related text.
Links and Images

Links connect documents and other resources on the web.

An anchor's href attribute specifies its destination.

Images should include useful alternative text so their content is available to everyone.

  • Use descriptive link text that explains where the link leads.
  • Provide an alt attribute for meaningful images.
Lists and Code

Lists organize related items into a clear, readable group.

Use an unordered list when item order is not important, or an ordered list when sequence matters.

The <code> element marks a short fragment of computer code.

  • Wrap each list item in an <li> element.
  • Use semantic elements to make documents easier to understand.
